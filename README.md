# Pandaro

**Stay focused. Stay panda.** A calm, panda-themed Pomodoro timer with tasks, statistics and a
small bamboo garden. Pandaro works offline, needs no account and keeps your data on your device.

> Status: in active development. See [WORK_LOG.md](WORK_LOG.md) for progress and verified checks.

```bash
npm ci
npm run dev       # http://localhost:5173
npm run verify    # format, lint, types, tests, build, end-to-end
docker compose up -d --build   # http://localhost:8080
```
